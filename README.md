### 🤖 Adaptive Interview Agent
> *ABTalks Vibe Coding Hackathon — Team Hexagon*

[![Live](https://img.shields.io/badge/⚡_LIVE-adaptive--interview--agent.vercel.app-00C7B7?style=for-the-badge)](https://adaptive-interview-agent.vercel.app/)

**AI-driven multi-turn interview engine** that adapts dynamically to each candidate's resume, curriculum, and live responses.

```
Stack     → React 18 · Express.js · Node.js
AI Core   → Groq LLM SDK (ultra-low latency)
Memory    → Breeth MCP (persistent session context)
Infra     → Vercel Frontend · Render Backend
Tests     → 6/6 Orchestration Tests Passing ✅
```

**Capabilities:**
- 🎯 8+ question personalized interview flows
- 🔄 Real-time adaptive follow-up generation
- 🧠 Persistent candidate memory (Breeth MCP)
- 📊 Structured feedback: Strengths, Gaps & Next Steps

## 📐 System Architecture

<details>
<summary><b>🤖 Adaptive Interview Agent — Architecture & Flow</b></summary>

<br/>

```
                  ╔═══════════════════════════╗
                  ║   React Frontend (Vercel) ║
                  ╚═══════════════╦═══════════╝
                                  ║ HTTPS REST
                  ╔═══════════════╩═══════════╗
                  ║  Express Backend (Render)  ║
                  ╚══╦══════════╦═════════════╝
                     ║          ║
           ╔═════════╩╗   ╔═════╩══════════╗
           ║  Session  ║   ║ Prompt Builder ║
           ║  Manager  ║   ╚═════╦══════════╝
           ╚═════════╦╝         ║ LLM Prompt
                     ║   ╔═════╩══════════╗
                     ║   ║  Groq LLM API  ║
                     ║   ╚════════════════╝
                     ║
           ╔═════════╩═════════╗
           ║    Breeth MCP     ║  ←── Persistent Memory
           ╚═══════════════════╝

INTERVIEW FLOW:
Candidate Selected
  └──▶ Start Interview
         └──▶ Load Context (candidates.json + curriculum.json)
                └──▶ Generate Question via Groq
                       └──▶ Record Answer + Update Progress
                              └──▶ Generate Follow-up (adaptive)
                                     └──▶ [Repeat × 8+ rounds]
                                            └──▶ Final Evaluation
                                                   └──▶ {
                                                           Summary ✅
                                                           Strengths ✅
                                                           Knowledge Gaps ✅
                                                           Next Steps ✅
                                                         }
```

</details>
