## 🔍 System Architecture & Engineering Deep Dives

<details>
<summary><b>🤖 Click to expand: Adaptive Interview Agent Architecture</b></summary>

<br/>

```text
                    React Frontend (Vercel)
                              │
                              │ HTTPS REST API
                              ▼
                    Express Backend (Render)
                              │
                    Interview Controller
                              │
          ┌───────────────────┼───────────────────┐
          ▼                   ▼                   ▼
   Session Manager      Prompt Builder       Data Layer
          │                   │          (candidates.json & curriculum.json)
          │                   ▼
          │           Groq LLM Service
          │                   │
          │                   ▼
          │               Groq API
          ▼
      Breeth MCP
  (Persistent Memory)
```

#### 🔄 Multi-Turn Interview Execution Cycle:
```text
Candidate Context ──▶ Start Session ──▶ Generate First Question
                                                │
                                                ▼
Structured Report ◀── Final Evaluation ◀── Candidate Response
  • Summary                                     │
  • Strengths                                   ▼
  • Knowledge Gaps ◀── (8+ Interactive Rounds) ── Record & Dynamic Follow-up
  • Next Steps
```

- **Contract**: Exposed via `POST /api/interview` supporting stateless session IDs, multi-turn state continuation, and deterministic prompt structures.
- **Privacy & Security**: Zero client-side API key exposure; all LLM credentials are securely isolated on the backend server.

</details>

│   └───────┬───────┘   └────────┬───────┘   └────────┬───────┘   │
│           │                    │                    │           │
│           ▼                    ▼                    ▼           │
│   SQLite Database      Local Ollama LLM     WhatsApp/SMS/Voice  │

└────────────────────────────────┬────────────────────────────────┘

- **Edge Intelligence**: Operates independently even without internet connectivity using on-device models.
- **Multilingual Accessibility**: Natural voice generation via `gTTS` ensuring seamless access for farmers speaking Hindi, Marathi, or English.
